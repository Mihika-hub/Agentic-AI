# Insurance Classification Problem

A machine learning project that predicts whether a customer is likely to buy insurance based on:

- `Age`
- `Monthly_Income`
- `Dependents`

The project includes model benchmarking, hyperparameter search scripts, and a Streamlit app for interactive predictions.

## Project Structure

- `app.py` – Streamlit app that trains multiple classifiers, compares accuracy, selects the best model, and allows live prediction.
- `benchmark.py` – Compares a broad set of classifiers and prints their accuracy.
- `tune_models.py`, `search_models.py`, `feature_search.py`, `ada_grid.py`, `xgb_search.py`, `threshold_test.py` – Model tuning and experimentation scripts.
- `realistic_insurance_classification_1000.csv` – Dataset.
- `best_insurance_model.joblib` – Serialized best model artifact.
- `benchmark_output.txt` – Saved benchmark results.

## Requirements

- Python 3.10+
- pip

Install dependencies:

```bash
pip install pandas scikit-learn streamlit joblib
```

## Run the Streamlit App

From this folder:

```bash
streamlit run app.py
```

The app will:

1. Load the dataset
2. Train and evaluate multiple models
3. Pick the best-performing model
4. Show metrics (accuracy, classification report, confusion matrix)
5. Provide an input form for prediction
6. Offer model download

## Dataset

Expected CSV file in the same folder:

- `realistic_insurance_classification_1000.csv`

Expected target column:

- `Bought_Insurance`

## Notes

- Training uses a fixed `random_state=42` for reproducibility.
- Most scripts use a 70:30 train/test split with stratification.
- The `.joblib` model file can be regenerated by running the app.
